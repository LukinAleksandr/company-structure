# company-structure

Демо: https://lukinaleksandr.github.io/company-structure/

## Требования

- Node.js 22+

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется по адресу http://localhost:5173/company-structure/

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | запуск в режиме разработки |
| `npm run build` | проверка типов и сборка в `dist/` |
| `npm run preview` | просмотр собранной версии |
| `npm run check` | форматирование и линтер (Biome) с автоисправлением |
